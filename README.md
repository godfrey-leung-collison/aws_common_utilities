# AWS Utilities 

This is a collection of utility functions or classes for interacting with AWS services such as S3, Lambda, and EC2, 
using python and `boto3` library.

Please also avoid pushing any data to this repo as well, whether raw or transformed data

> [!IMPORTANT]
> Please do not upload any IP data (except test mock data) or credentials like API keys (at least not without using secrets) to the repo

Tips: You can store the data in your local machine under some directories and include those directories in the `.gitignore`
file such that they won't get pushed/commited in git, e.g. add these lines in `.gitignore` file

The scripts have been tested in Python 3.12 (on M1 Mac)
